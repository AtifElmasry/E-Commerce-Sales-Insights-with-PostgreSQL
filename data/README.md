# Dataset

The analysis retrieves UCI Online Retail dataset ID 352 directly with `ucimlrepo`.

Source: https://archive.ics.uci.edu/dataset/352/online+retail  
DOI: https://doi.org/10.24432/C5BW33  
License: CC BY 4.0

The raw data is not copied into the repository. Running `src/retail_analysis.py` creates analysis-ready CSV files under `data/processed/`.
